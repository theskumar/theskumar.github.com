[viewflow/seedkit](https://github.com/viewflow/seedkit) is an agent skill that scaffolds a Django project by asking you questions, then writes only the parts you picked. The edge over cookiecutter: it also works on a live repo. `/django-seedkit add proper auth` inventories what exists and wires the new package in midway: deps, settings, `.env` example, CI step. A deterministic generator runs once, on day zero.

The layout is the part worth copying. One `SKILL.md` walks the questions and routes each answer to exactly one file in `references/` (`auth.md`, `billing.md`, `tasks-celery.md`, about 50 of them). Each file keeps only what the model gets wrong: current setting names, current packages. Their benchmark: Sonnet 5 with the skill passed 72 of 72 security and config checks across nine projects; Fable 5 without it missed about a quarter.

The pattern generalizes past Django: one orchestrator skill that asks the questions, plus a reference pack per stack (Django, Next.js, Flutter). Seedkit ships only the Django pack today.
