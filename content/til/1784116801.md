[gistpreview.github.io](https://gistpreview.github.io/) renders any GitHub Gist as a live HTML page. Pass the gist ID as a query param (`?<gist_id>`) and it fetches via GitHub API + `document.write()`. Entire thing is 2 files (index.html + main.js), no build step, trivially self-hostable. Useful for quick HTML/CSS demos without spinning up CodePen or deploying anything.
