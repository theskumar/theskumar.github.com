Vim motion tips for Zed. Turn on relative line numbers, and let [vim mode](https://zed.dev/docs/vim) switch them to absolute in Insert mode, so you get jump distances in Normal mode and context while typing.
```json
{ "relative_line_numbers": true, "vim": { "toggle_relative_line_numbers": true } }
```
- `[[` / `]]` jump between function definitions in a large Django or FastAPI file.
- `f:` moves to the end of an `if`, `def` or `class` line.
